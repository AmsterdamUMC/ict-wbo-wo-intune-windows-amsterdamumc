# Description
This project contains files that are used for the Amsterdam UMC Windows devices, managed by Intune. 

# Layout
Project is currently devided into folders; 
* `wallpaper` - contains the wallpapers that are used on the Intune devices.

The wallpapers are set with a [PowerShell script from Oliver Kieselbach](https://oliverkieselbach.com/2021/02/23/set-preference-for-a-suitable-wallpaper-with-intune/), modified for our usage.
